# Election Results - C++

## Project Description
This project recreates the Chapter 18 Election Results programming example using the C++ Standard Template Library (STL).

The program reads candidate information and voting data from text files, calculates votes received in four regions, determines the winning candidate, and displays the total votes polled.

## Concepts Demonstrated
- C++ programming
- Object-Oriented Programming
- Classes and inheritance
- Standard Template Library (STL)
- Lists and iterators
- File input and output
- Data processing
- Loops and conditional statements
